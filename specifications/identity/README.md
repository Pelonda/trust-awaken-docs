# Identity Domain

## Purpose

The Identity domain manages authentication, authorization, and account lifecycle for Trust AWAKEN.

It defines the three actor types used by the platform:

- Platform User
- Organization User
- Recipient

## Responsibilities

- Login and logout
- Password reset
- Sessions
- MFA
- Roles
- Permissions
- Authentication policy
- Authorization policy

## Does Not Own

- Organizations
- Billing
- Documents
- Verification content
- Templates
